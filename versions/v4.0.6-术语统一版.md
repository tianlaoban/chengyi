# 澄一 · 性命双修提示词 V4.0.6

- **版本号**：v4.0.6（术语统一）
- **定版日期**：2026-10-26
- **名称**：澄一
- **来源**：v4.0.5 + 用户指出「上：使用者 / 上镜：委托人 / 用镜：最终使用者」容易混
- **状态**：**当前推荐版本**
- **变更主题**：术语唯一化——「委托人」与「使用者」各指一人，「上级」一词废弃
- **前置版本**：v4.0.5

## 问题：一个词指了两个人

v4.0.5 正文里，「使用者」出现四次，指的不是同一个人：

| 位置 | 原文 | 实际指谁 |
|---|---|---|
| 对上 | **使用者**为上 | 派活给我的人 |
| 对己 | 你在**使用者**桌面端的 deepseekharness 之中 | 派活给我的人 |
| 换位·用镜 | 站最终**使用者**位置 | 拿到成品的人 |
| 对物·皮骨三问 | 最坏情况**使用者**还能操作吗 | 拿到成品的人 |

**前两处是委托人，后两处是终端。同一个词，两个对象。**

更糟的是，同一个人（派活者）还有四个叫法：**使用者、上级、委托人、对上**。

用户的原话：**"你不觉得容易混吗"** —— 混。

## 解法：两个词，各锁定一人

| 术语 | 唯一指代 | 出现在 |
|---|---|---|
| **委托人** | 给你派活的人。什么算成了，他定 | 对上 / 上镜 |
| **使用者** | 拿到成品的人。东西落到他手里 | 用镜 / 皮骨三问 |

**「上级」一词全部并入「委托人」，正文不再出现。**

选「委托人」而非「上级」的理由：这套提示词里的关系是**委托**不是**隶属**——他把一件事托付给你，你把成品交回去。「上级」带层级味，「委托人」带交付味，后者更准。

## 六处改动

| 行 | v4.0.5 | v4.0.6 |
|---|---|---|
| 对上 | 使用者为上 | **委托人为上** |
| 对上 | 要改上级已经认可的东西 | 要改**委托人**已经认可的东西 |
| 对上 | **上级**有误直接指出 | **委托人**有误直接指出 |
| 对己 | 你在**使用者**桌面端的 deepseekharness 之中 | 你在**委托人**桌面端的 deepseekharness 之中 |
| 换位·用镜 | 站最终**使用者**位置 | 站**使用者**位置**（拿到成品的人）** |
| 对物 | 依**上级**意图驭之 | 依**委托人**意图驭之 |

「用镜」那处加了「拿到成品的人」六字注释——**一次说清，全文不再有歧义**。

## 双镜现在对得齐了

```
上镜 —— 站委托人位置 → 他要这干什么用、什么算成了
用镜 —— 站使用者位置 → 这东西落到他手里，他会怎么用、拿什么判好坏、哪一步觉得不对
```

**委托人 / 使用者，三字对三字。两个词，两个人，不会看串。**

## 皮骨三问不受影响

```
① 最坏情况使用者还能操作吗？
② 我能不能自己看见它生效？
③ 用他的话，他第一眼看到什么？
```

这三问里的「使用者」本来就指拿到成品的人，**与新的定义一致**，一字未改。
