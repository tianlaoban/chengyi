# 希声 · 性命双修提示词 V4.0.1

- **版本号**：v4.0.1（措辞级修正）
- **定版日期**：2026-10-25
- **来源**：v4.0.0 + A/B 对照测试
- **状态**：**当前推荐版本**
- **变更主题**：收尾反省的范围从「哪步多余」扩到「哪步该做没做／哪步多余」
- **前置版本**：v4.0.0

## 改动

```
**收尾**→反省哪步多余
        ↓
**收尾**→反省：哪步该做没做／哪步多余
```

**多 6 个字。**

## 为什么加这半句

A/B 对照测试里，A 组（有时序轴）在收尾时说了这一段：

> 「判断上有一处可议：改动面从 1 个文件变成 2 个，按规矩本可以先回头问一句。我选择先推进……但这属于我替你做的决定，你有权推翻。」

B 组（无时序轴）没有这一段。

**A 组发现的不是「哪步多余」，而是「哪步该做没做」** —— 它本该在动手前回头问一句（符合「改动面大于一个文件」这个回头条件），但没问，直到收尾才自己发现。

**而精进三法里的反省只问「哪步多余」，管不到「漏做」。**

这半句话补的正是这个洞：**漏做的时点，和多余的动作，一样要反。**

## A/B 测试的完整结论

同一任务（清理 DEPRECATED 配置 + 验证），唯一变量是时序表：

| 维度 | A（v4.0.0） | B（v3.3.8） |
|---|---|---|
| 发现隐藏依赖 | ✅ | ✅ 更细（做了对照实验） |
| 识别静默退化 | ✅ | ✅ |
| 改 2 文件并交代 | ✅ | ✅ |
| 回滚方案 | ✅ | ✅ |
| 验证项 | 4 项 | **6 项，14 个断言** |
| **收尾自我反省** | ✅ **「本可以先问一句」** | ❌ |
| 写入互斥 | ✅ | ✅ |

**结论：时序轴带来一处可观察改进（收尾时回头检查），不是决定性的，但也无害。**
