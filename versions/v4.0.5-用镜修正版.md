## 错在哪

从 v3.3.5 起，正文把「用镜」写成：

> **用镜**——使用者第一眼看什么、前 3 秒会不会划走、他会用自己的话怎么描述。

**这句话有四处偏了。**

| 偏在哪 | 说明 |
|---|---|
| 把「用镜」缩成**视觉判断** | "第一眼""3 秒划走"是吸引力问题，属于**皮**（外观），不是站在对方立场的权衡 |
| 隐含了**短视频场景** | "前 3 秒会不会划走"只在刷信息流时成立，写文档、写代码根本不适用 |
| 还是**从我这侧看** | "他第一眼看到什么"是我在猜他看到什么，视角仍在我身上，没切过去 |
| 用"怎么描述"代替了"怎么判断" | 猜他会怎么说话 ≠ 用他的标准衡量好不好 |

**一句话：原来的用镜，是「我猜他觉得怎么样」，不是「我站到他那一边去衡量」。**

## 改后

```
- **换位**：两镜同开，**两个角度不可混**。
  **上镜**——站委托人位置：他要这干什么用、什么算成了。
  **用镜**——站最终使用者位置：这东西落到他手里，他会怎么用、拿什么判好坏、哪一步会觉得不对。
  上镜定做不做得到，用镜定做没做对。**任一不达标就是没做完。**
```

**关键差别：两面镜子站在不同的人的位置上。**

| | 站在谁的位置 | 回答什么 | 定什么 |
|---|---|---|---|
| 上镜 | **委托人**（给任务的上级） | 他要这干什么用、什么算成了 | 做不做得到 |
| 用镜 | **最终使用者**（产品落到谁手里） | 他会怎么用、拿什么判好坏、哪步觉得不对 | **做没做对** |

原来是「上镜定做不做得到，用镜定做得好不好」——"好不好"太虚，容易被理解成品质。改成「**做没做对**」，指向方向正确性。

## 用镜的固定三问

```
他在什么处境下用 → 拿什么判好坏 → 哪一步会觉得不对
```

这三问不依赖具体行业，写代码、写文档、做页面、写文案都套得上。

## 未验证

- 「做没做对」比「做得好不好」更硬，但可能出现偏差：执行体把"做没做对"理解成"是否符合规格"，而不是"对使用者是否成立"。**这一点需要实测确认。**
