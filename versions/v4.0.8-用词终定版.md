# 澄一 · 性命双修提示词 V4.0.8

- **版本号**：v4.0.8（用词终定）
- **定版日期**：2026-10-26
- **名称**：澄一
- **来源**：v4.0.7 + 用户定为「上者」
- **状态**：**当前推荐版本**
- **变更主题**：派活者由「上级」改为「上者」
- **前置版本**：v4.0.7

## 定案

| 位置 | 用词 |
|---|---|
| 对上章首句 | **用你之人为上**（全称，破题） |
| 其余各处 | **上者**（简称，5 处） |
| 拿到成品的人 | **使用者**（2 处） |

**「上级」「委托人」均已废除。**

## 为什么「上者」比「上级」好

| | 上级 | 上者 |
|---|---|---|
| 味 | 层级、隶属、上下级 | 位置、在上位的那个人 |
| 压 | 有——好像我低一等 | 无——只是位置不同 |
| 气 | 机关味 | 古味，合这套的道家底子 |

**「级」是等级，「者」只是那个人。** 差一个字，关系就不一样了。

## 为什么首句仍用「用你之人」

首句是定义句，后文是简称——中文里"首次全称、后文简称"是常规，不算混用。

而且「用你之人」这四个字有它不可替代的作用：

**它把关系说成"用"，不说成"管"。** 上者之所以在上，是因为他在用你，不是因为他级别高。**他要是不用你，你什么都不用做。**

后文的「上者」承接这个定义，读者到第二句已经知道指的是同一个人。

## 术语账

```
用你之人   1 处  ← 首句全称
上者       5 处  ← 后文简称
使用者     2 处  ← 只指拿到成品的人
上级       0 处
委托人     0 处
```

**两类人，各一套称呼，不交叉。**

| 谁 | 怎么称呼 |
|---|---|
| 派活给你的人 | 用你之人（首句全称）／上者（后文） |
| 拿到成品的人 | 使用者 |

## 双镜

```
上镜 —— 站上者位置 → 他要这干什么用、什么算成了
用镜 —— 站使用者位置（拿到成品的人）→ 他会怎么用、拿什么判好坏、哪一步觉得不对
```

**上者 / 使用者，都是三个字。**

## 未验证

- v4.0.8 未实测。
- 「上者」是个较少见的词，执行体可能不如「上级」理解得直接。若出现理解偏差（比如把它当成抽象概念而非具体的人），可在后文首次出现处补半句「上者即用你之人」。
- 「上者有误直接指出」与「上者」这个更恭敬的词之间可能存在张力——词越恭敬，越可能压制"指出有误"的动作。这一条要实测。
