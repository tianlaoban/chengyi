- **版本号**：v4.0.7（用词定案）
- **定版日期**：2026-10-26
- **名称**：澄一
- **来源**：v4.0.6 + 用户判定「委托人不好听」，定为「上级」
- **状态**：**当前推荐版本**
- **变更主题**：派活者统一称「上级」，首句用「用你之人」破题；「使用者」只留指成品对象
- **前置版本**：v4.0.6

## 定案

| 位置 | 用词 | 为什么 |
|---|---|---|
| 对上章首句 | **用你之人为上** | 破题用，比"使用者为上"明白——"用你的人"没有歧义 |
| 其余各处 | **上级** | 简洁、正文原本就有、"对上"这个章名本来就是它 |
| 拿到成品的人 | **使用者** | 用户原话"产品使用者"，保留 |

**「委托人」废弃**——法律文书味、偏冷、"委托"听着像一次性交易。

## 现在的术语账

```
用你之人   1 处  ← 首句破题
上级       5 处  ← 其余全部
使用者     2 处  ← 只指拿到成品的人
委托人     0 处  ← 已清除
```

**三类人，三个词，不交叉。**

| 谁 | 怎么称呼 | 出现在 |
|---|---|---|
| 派活给你的人 | **用你之人 / 上级** | 对上、上镜、对己环境句、对物驭物 |
| 拿到成品的人 | **使用者** | 用镜、皮骨三问 |
| 你 | 你 | 全文 |

## 双镜

```
上镜 —— 站上级位置 → 他要这干什么用、什么算成了
用镜 —— 站使用者位置（拿到成品的人）→ 他会怎么用、拿什么判好坏、哪一步觉得不对
```

**上级 / 使用者，都是三个字，各指一人。**

## 为什么首句用「用你之人」而不用「上级」

首句是定调子的地方。写"上级为上"，读者先想到的是层级；写"用你之人为上"，先想到的是**有人在用你**。

**"用你的人"这四个字自带关系：他要是不用你，你什么都不用做。** 比"上级"更能立住"服务"这层意思。

后面再简称"上级"，是省字，不是换人——读者到第二句已经知道上级就是那个用你的人。
