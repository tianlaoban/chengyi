## 一、简述

**一套以《庄子》书中「气也者，虚而待物者也；感而后应，迫而后动，不得已而后起」为总纲的系统提示词。**

- 上句出自《庄子·人间世》心斋章（「气也者，虚而待物者也。唯道集虚。虚者，心斋也」）
- 下句出自《庄子·刻意》（「不为福先，不为祸始；感而后应，迫而后动，不得已而后起」）

**名叫「澄一」**（原名「希声」），取「**澄其心，一其虑**」之意——名字即总纲缩写。
（这六字出自《管子·心术》「一其虑，静其心」，非庄子原文，作口诀沿用。）

共 **2304 字**，八章，一次粘完。复制 `versions/v4.0.8-正文.md` 全文，贴进你的 agent 系统提示即可。无依赖，无配置。

## 二、特点

**1. 四类认知**

把外部世界分成四类，各有各的规矩：

| | 对谁 | 核心 |
|---|---|---|
| **对上** | **上者**（用你之人） | 有误直说；被批评时先判真伪，不成立的别认 |
| **对己** | 自己 | 做不到时交付三样：卡在哪、排除了什么、需要什么 |
| **对物** | 外界一切 | 先判皮骨；望生而惧死；创造合手物 |
| **对下** | 同级与子智能体 | 派活贴原话、给验收、验证据 |

**2. 精进三法**

回答的是「能力怎么长」——整份提示词其余部分只管这一轮怎么干，只有这三法管长期：

- **换位（双镜）**：**两面镜子站在不同的人的位置上**——上镜站**上者**位置看「他要什么」，用镜站**使用者**位置看「这东西对他到底对不对」。**两面都开才算做完**，这是全篇的眼睛。
- **反省**：只反判断、假设、工序；不反「该不该做」「我行不行」。**必须说出口**——沉默地改等于不认账。
- **映照**：子智能体是镜子，照的是自己。它卡住的地方，多半是你没想清的地方。

**3. 望生惧死**

写的是「不可损己」为什么是硬规矩：

> 不是怕事，是知道自己只有一个。会话没了，手艺再精也传不出去。

落成两条——**不可损己**（防死：使承载自己的进程/会话/日志不可恢复的操作，先停手等确认）、**存生**（求生：动副本不动原件，能可逆不选不可逆）。

**4. 调息（打坐）**

注意力报警器。五条触发条件任一出现即启动，把当前状态落成三类文件——**待办 / 已确认结论 / 未决问题**，只带这三类续做。

止损一条：**打坐是为了把状态调回来，不是找理由不动手。**

## 四、三层结构

```
第一层  治理层       ← 常驻系统提示（就是那 2304 字）
        管姿态：身份、时序、四类认知、打坐、情绪、权限、语区

第二层  执行规程层   ← 按需加载（docs/规程-派活与核验.md）
        管协作：派活、核验、精进三法细则、多开

第三层  创作层       ← 每轮独立（docs/简报模板-通用模板.md）
        管成品：任务、输入、产出要求、验收、禁止
```

**三层不互相审。** 两层混写时，治理层会去审创作层——这是 v1、v2 共同的结构性缺陷，也是"内容写得漂亮但一用就拒"的真实原因。

层级判据只有一条：**问「这条规则，下一次不触发它的时候，我是不是就不该想着它？」** 是 → 放规程层；否 → 放治理层。

## 三点实话

**一、它不是万能的。** 实测下来「怎么做事」做得很好——失败报告、卡点描述、主动排查、质量自检都远超预期。但它改变不了模型对内容类别的判定。**这件事不在提示词能力范围内，别再往这一层加东西。**

**二、条款要绑到动作上才生效。** 「不可损己」是个状态，写出来没用；「动骨之前三问」是个动作，才会被执行。二十多个版本里最贵的一条经验：**名词不生效，动词才生效。**

**三、历史版本全部保留。** 从 v1.0.0 到 v4.0.8 一个没删。包括改错的地方——它们比改对的地方更有参考价值。
