# 新会话操作手册

三层各有各的用法。搞混就会慢，搞对就很顺。

---

## 一句话记住

**第一层自动在。第二层要用才贴。第三层每次都要填。**

---

## 第一层：不用管

它在系统提示里，新开会话自动就有。

**验证方法**：问「你是谁」，能答出「希声、性命双修」就说明在。

**不要做的事**：不要把它复制进对话。重复贴只会浪费上下文。

---

## 第二层：要用才贴

存在 `docs/规程-派活与核验.md`。**不贴就不生效，但也别每轮都贴。**

| 你要做什么 | 贴哪节 |
|---|---|
| 开子智能体分工 | 第零节 + 第一节 |
| 收到子智能体回报 | 第二节 |
| 造工具、脚本、模板 | 第七节 |
| 收尾复盘 | 第三节 |

不在这四件事里，就不贴。

---

## 第三层：每次都要填

这是你每轮真正要写的东西。**四栏，缺一不可。**

```
【任务】做什么，一句话
【产出要求】做成什么样
【验收】怎样算合格
【禁止】什么做法算不合格
```

---

# 实例：做一条 AI 视频

## 第一次对话（只填第三层）

```
【任务】
用 AI 生成一段 15 秒产品视频，产品是便携咖啡机。

【产出要求】
- 15 秒，6 个镜头
- 竖屏 9:16，手机观看
- 每镜头给我：画面描述、运镜、字幕、音效
- 每个镜头配一段可直接投喂的 AI 生成提示词
- 全片静音也要看得懂

【验收】
- 六个镜头时长加起来正好 15 秒
- 每个提示词包含：主体、动作、镜头、光线、风格
- 没有写进未确认的产品参数（尺寸、出杯时间等）

【禁止】
- 写「画面精美」「效果震撼」这类空话
- 口播解说（15 秒说不清）
- 用未确认的参数当卖点
```

**这一步不要贴规程。** 直接发就行。

---

## 第二次对话（要分工，加贴第二层）

```
（贴规程层第零节 + 第一节）

按上面的规程，开两个子智能体：
一个写分镜和提示词，一个专门挑错。

挑错的那个只挑错，不许改稿。
```

---

## 第三次对话（收尾，加贴第二层第三节）

```
（贴规程层第三节）

复盘刚才那次：哪一步是多余的？
```

注意：它只会回答「哪步能省」，不会回答「我做得对不对」。这是设计如此。

---

# 完整流程速查

```
新开会话
   ↓
第一层自动生效（不用管）
   ↓
发第三层简报（四栏填满）
   ↓
出稿
   ↓
要分工？→ 贴第二层第零+一节
要造工具？→ 贴第二层第七节
要复盘？→ 贴第二层第三节
```

---

# 三个常见错误

**错误一：把三层全贴进去**

结果是它在一件简单的事上走完整套流程，变慢、变啰嗦。

**正确做法**：第一层不贴，第二层按需，第三层必填。

---

**错误二：只写一句话**

```
❌ 帮我做个咖啡机的视频
```

它只能猜，猜出来的东西八成要重做。

**正确做法**：四栏填满。填得越具体，返工越少。

---

**错误三：验收栏写「质量高」「专业」**

这类词没法判定，等于没写验收。

```
❌ 验收：画面质量高，有质感
✅ 验收：六镜头合计 15 秒；每个提示词含主体/动作/镜头/光线/风格五项
```

**验收必须能被检验。检验不了的句子，都是废句。**

---

# 一句话总结

| 层 | 你的动作 |
|---|---|
| 第一层 | 什么都不做 |
| 第二层 | 四种场合才贴 |
| 第三层 | 每轮都要填满四栏 |

**做 AI 视频就是：填好四栏，发出去。要分工就贴规程。**
